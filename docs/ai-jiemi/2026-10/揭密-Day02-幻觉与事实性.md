## 题目一：先把两种失败分开

### 作答区

#### 1. 笔记里的划分

综述用了两个例子，划分标准是「错在和谁比」：

| | 和谁不一致 | 笔记中的例子 | 世界事实可以仍然成立吗 |
|---|---|---|---|
| 幻觉（综述用法） | 和提示要求比 | 要求写兔子和狼做朋友，写成兔子和狗 | 可以。狗和兔子做朋友这件事不必是假的 |
| 事实性问题 | 和世界或和应有的信息比 | 回避成「我不知道」，或答案方向对但漏了关键事实 | 这本身就是事实性失败，综述不把它叫幻觉 |

再补一条笔记里强调的边界：输出比提示多了细节，只要那些细节和世界相符，综述仍把它归到幻觉（没按提示来），不归到事实性错误。

这个用法和工程口语相反。工程口语里「幻觉」往往指「说了上下文和世界都支撑不住的内容」。两套用法可以并存，条件是每次指出在和谁比。

> 说法陷阱：把「我不知道」叫幻觉。按这篇综述，拒答是事实性策略的一种表现：模型没有给出该给的事实。它可能是期望中的行为（没有证据就停），也可能是失败（证据在上下文里却不敢用）。要看证据在不在，不能看语气像不像认错。

#### 2. 排障时用的四层，比两个词更有用

综述的二分回答「错在和谁比」。排障还要回答「错是在哪一层种下的」。把笔记后半的原因分析收成四层：

| 层 | 错误长什么样 | 典型来源（笔记中的条目） |
|---|---|---|
| 提示约束 | 体裁、角色、必选元素没按提示来 | 兔子写成狗；多出来的情节 |
| 参数知识 | 实体、时间、领域事实对不上世界 | 缺少领域知识、知识过时、没记住语料、遗忘 |
| 检索证据 | 上下文里的证据不足、互相打架，或模型读偏了 | 信息不足、接受了错误材料、干扰句、长文中间位置、曲解相关段落 |
| 解码路径 | 开头一小步偏了，后文跟着偏 | 滚雪球、解码选错、语料高频说法把用词拉偏 |

一张坏答案可以跨层，但主因只有一个修补入口。入口选错，后面的温度、提示词和检索都会加在错误的层上。

## 题目二：三层原因分别怎么发生

### 作答区

#### 1. 模型层：权重里的事实本来就不稳

笔记列了五条，翻译成 Day01 的语言：

1. **缺少领域知识**：私有文档、内部口径不在预训练分布里。通用语料学到的是语言和公开世界的一部分，不是某家公司的表。
2. **过时**：参数停在训练截止日。截止日之后的电影、价格、人事，分布里没有对应的新事实。
3. **记忆化失败**：语料里出现过，不表示推理时那个实体的条件概率最高。
4. **遗忘**：后续训练把原来的高概率压下去了。
5. **推理失败**：事实片段都在，组合步走错。这不是「没见过这个词」，是路径在中途分叉错了。

微调笔记里有一条和「遗忘 / 分布」连得上：对话微调之后，如果输入说法和训练说法差得远，模型不走训练集里的回答，而退回原来的生成。看起来像「微调没学会」，实际是条件离开了训练过的邻域。

#### 2. 检索层：证据进了上下文，仍会答错

笔记写了五条，每一条都否定「检索到了就等于会用」：

1. **信息不足**：召回的片段没有答题所需的细节，模型用通用说法把洞填上。
2. **接受错误材料**：检索结果本身是错的，模型照着说。知识冲突时（检索和参数记忆矛盾，或多篇文档互相矛盾）更明显。笔记的观察是：证据越不相关，模型越退回参数知识。
3. **干扰句**：片段里同时出现「俄罗斯电影」和「导演」，模型接成「导演是俄罗斯人」。多余实体会进入下一步的条件。
4. **位置**：长检索上下文里，开头和结尾更好用，中间的证据更容易被丢掉。所以「窗口够长」不保证中间那段被用到。
5. **曲解**：片段相关，阅读步仍然可以抽错关系。检索优化能减少这种情况，不能把它变成零。

这五条是 Day03 的验收单。RAG 加上去之后，要用这五条而不是用「还幻不幻觉」来看。

#### 3. 解码层：错误会自己变成条件

1. **滚雪球**：第一句的错误前提写进上下文，后面的 token 只能条件于它，偏差被放大。降温让这条错误路径更稳，不会把前提改回去。
2. **解码偏离模型自己的高概率**：beam 或采样走到一条和「模型最倾向的说法」不一致的路径，表面上像自相矛盾。这时才值得看解码配置。
3. **高频说法**：笔记称为暴露偏差，指的是训练里常见的措辞和设定被优先生成，例如性别表述偏向语料里的常见类别。现象是真实的。名字容易和另一件事混淆：序列训练里的 exposure bias，指训练时下一步看的是真值 token，推理时看的是模型自己写下的 token。排障记录里写「被常见说法带走」或「推理时离开了训练条件」，不要只写一个未加定义的「暴露偏差」。

## 题目三：补救必须对上层

### 作答区

| 你看到的现象 | 先查的层 | 对得上的动作 | 对不上的动作 |
|---|---|---|---|
| 故事元素和提示不符，事实未必错 | 提示约束 | 分隔符、输出结构、少样本把格式钉住 | 换一个更大的百科知识库 |
| 公开知识过时、私有事实没有 | 参数知识或检索 | 把新证据放进上下文，或接受截止日 | 只把温度调到 0 |
| 检索结果互相矛盾，回答跟着某一段跑 | 检索证据 | 过滤、对来源做核对、缩短并标出证据位置 | 再加一个不会看证据的代理 |
| 第一句错，后面越写越圆 | 解码路径 | 截断重生成、强制先引用再作答、降低这条路径的重复 | 相信后文会自己纠正 |
| 有证据仍回答「不知道」 | 提示约束或阅读步 | 看证据是否在中间位置、提示是否把拒答写得过强 | 把它记成幻觉然后加大检索条数 |

笔记在 RAG 原理里还写了一条：希望模型没把握时礼貌拒答，这主要靠提示词，而且在弱模型上不稳定。拒答是一条生成路径，不是一个独立的真值判断器。它会和「证据相关但模型退回参数知识」同时出现，要用「证据在不在上下文里」来区分。

## 本日能力差距与补足方向

### 差距1：一个词覆盖所有答错

- **现状**：答错、跑题、拒答、过时，都记成幻觉。
- **核对后的水平**：先写「和提示比」还是「和世界比」，再写四层里的主因。
- **补足方向**：拿十条例子只标主因。标不出主因的，把上下文和提示原文留下，不要先改模型。

### 差距2：检索层的五种失败没有检查单

- **现状**：召回非空就认为 RAG 生效。
- **核对后的水平**：能指出不足、错误材料、干扰、位置、曲解各自的样子。
- **补足方向**：Day03 用这五条做链路验收，不另起一套形容词。

### 差距3：滚雪球被当成需要更多知识

- **现状**：后文离谱就补充背景文档。
- **核对后的水平**：先看第一个错 token 出现在哪里。若错误从那一个 token 开始条件化，先截断，再决定要不要新证据。
- **补足方向**：把坏答案从出错处截断重新生成，对比后文是否还沿同一方向滑。

## 附录：本日关键认知速查

| 认知点 | 关键结论 |
|---|---|
| 综述里的幻觉 | 输出偏离提示要求，世界事实仍可能正确 |
| 综述里的事实性 | 和世界或应有信息不符；拒答和遗漏算在这里 |
| 工程口语 | 常把「无证据的具体陈述」叫幻觉。使用时要声明在和谁比 |
| 模型层 | 没学过、过时、记得不稳、被后续训练盖住、组合步走错 |
| 检索层 | 不够、材料错、干扰实体、中间位置、读偏关系 |
| 解码层 | 早错变条件，后文滚雪球 |
| 高频说法 | 语料常见措辞占优；与 teacher forcing 的 exposure bias 不是同一个机制 |
| 降温 | 稳住当前高概率路径，不补充事实 |
| 拒答 | 一条被提示词推动的路径，要对照证据是否真的缺失 |
