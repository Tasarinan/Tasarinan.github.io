# Agent-记忆评测与安全护栏

这篇是我基于项目实践与资料交叉阅读整理的学习笔记，目标不是复述概念，而是沉淀可直接复用的工程动作与判断标准。


当Agent进入持续协作场景，记忆与安全不再是可选项，而是系统底座。

## 一、记忆体系设计

建议拆成两类：
1. 短期记忆：当前任务过程状态
2. 长期记忆：跨任务经验与规则

关键在边界：短期信息不能无筛选沉淀到长期库。

## 二、记忆质量评测

评测至少覆盖：
- 命中率（该记住的是否召回）
- 纯净度（错误记忆比例）
- 时效性（过期信息淘汰速度）

必须结合线上样本与离线回放双重验证。

## 三、安全护栏体系

安全建议三层：
1. 指令层：危险指令识别与拦截
2. 工具层：高风险工具权限控制
3. 数据层：敏感信息脱敏与访问审计

只做内容审核不足以保证系统安全。

## 四、风险隔离与应急

出现异常时，应支持：
- 快速停用问题记忆分片
- 切断高风险工具路由
- 回退到保守策略模板

应急流程越标准，业务损失越低。

## 五、常见失败模式

1. 记忆污染：错误事实长期保留。
2. 权限越界：低权限任务触发高风险工具。
3. 日志缺失：事故后无法审计和追责。

## 六、建议指标

- 记忆命中率与误命中率
- 过期记忆清理时效
- 安全拦截命中率
- 高风险操作二次确认覆盖率
- 安全事件恢复时长

## 七、结论

记忆提升连续性，护栏保障可控性。两者一起做，Agent系统才能在真实业务里长期可信运行。
