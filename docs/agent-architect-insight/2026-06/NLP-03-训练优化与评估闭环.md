# NLP-训练优化与评估闭环

这篇是我基于项目实践与资料交叉阅读整理的学习笔记，目标不是复述概念，而是沉淀可直接复用的工程动作与判断标准。


训练阶段决定能力上限，评估闭环决定能力是否可信。离开评估和回归的训练优化，通常只是局部提升。

## 一、训练前置：先定契约

训练前要冻结四类契约：
1. 输入字段
2. 标签定义
3. 负样本策略
4. 评估口径

没有契约，跨版本结果无法比较。

## 二、训练优化主线

### 1) 数据优先于参数

大量实践显示：数据质量提升通常比盲目扩数据量更有效。先做噪声清洗、口径统一，再做参数搜索。

### 2) 单变量迭代

每轮只调整一个核心变量（学习率、batch、损失函数之一），否则无法归因。

### 3) 过拟合防线

监控 train/eval gap，必要时采用早停、正则、数据增强。不是 loss 下降越多越好。

## 三、评估闭环设计

完整闭环应包含：
- 离线评测（能力上限）
- 小流量灰度（真实分布）
- 线上监控（漂移与稳定）
- 失败样本回流（下一轮训练输入）

## 四、常见失败模式

1. 只看单一指标，忽略关键子场景退化。
2. 使用“最好看”的checkpoint，实际泛化最差。
3. 微调后领域指标提升，但通用能力明显塌陷。

## 五、建议指标

- 核心任务：Precision/Recall/F1
- 稳定性：跨批次波动、长尾样本表现
- 校准性：置信度与正确率一致性
- 回归性：新版本对旧版本关键集不退化

## 六、实战案例

在客服意图识别任务中，初版模型线上波动大。团队改为“固定评测集 + 失败样本周回流 + 早停策略”。
结果：线上F1稳定提升，问题定位周期由周级降到天级。

## 七、结论

训练优化不是“找一次最优参数”，而是“建立长期可复现的迭代系统”。闭环完整，模型能力才会持续增长。
## 学习者复盘

这轮整理里，我刻意保留了三类内容：
1. 真正会踩坑的决策点。
2. 可以落到监控面板的指标。
3. 能在下次项目里直接复用的流程模板。

后续继续学习时，我会优先补两块：
- 增加失败样本复盘（不仅保留成功路径）。
- 增加跨场景迁移对比（同方法在不同业务下的边界）。
