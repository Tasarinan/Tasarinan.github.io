# NLP-语料基础与预处理体系

这篇是我基于项目实践与资料交叉阅读整理的学习笔记，目标不是复述概念，而是沉淀可直接复用的工程动作与判断标准。


这篇笔记聚焦一个核心事实：NLP效果的上限，首先由语料工程决定。模型只是放大器，语料质量才是底座。

## 一、语料建设目标与边界

语料建设不是“收得越多越好”，而是“任务相关、标签可靠、分布稳定”。

必须先定义三件事：
1. 任务边界：要解决哪些问题，不解决哪些问题。
2. 标签口径：同一类样本必须给出同一判定标准。
3. 覆盖范围：核心场景 + 长尾场景都要有样本。

## 二、预处理流水线

### 1) 抽取与标准化

多源数据常见格式包括 PDF、HTML、Markdown、表格。实践里最难的是 PDF：多栏、表格、脚注会破坏阅读顺序。

标准化动作建议固定为：
- 编码修复（UTF-8统一）
- 全角半角统一
- 异常符号清理
- 段落边界重建

### 2) 去重与噪声清洗

只做字面去重不够，必须做语义近重检测。建议分两层：
- 局部哈希去重（高效）
- 向量相似去重（稳健）

常见噪声包括广告模板、短无义句、乱码、错语种混入。对边界样本不要直接删，放入灰区复核池。

### 3) 切分与结构化标注

按字数切块最容易导致语义断裂。更稳的做法是“段落语义优先 + 长度约束补充”：
- 先按自然段和小节切分
- 再按最大 token 限制二次切割

标注阶段必须先冻结标签体系，再启动标注；否则后期返工成本极高。

## 三、工程中的高频坑

1. PDF抽取顺序错误，导致事实链条断裂。
2. 去重不彻底，训练集被重复模板污染。
3. 标签定义漂移，不同批次标注口径不一致。
4. 语料版本缺乏追踪，线上问题无法回溯到数据变更。

## 四、关键指标与验收标准

建议至少维护以下指标：
- 抽取成功率：>= 95%
- 重复率：<= 5%
- 标签一致率（双标注抽检）：>= 85%
- 噪声占比：逐月下降
- 语料变更可追溯率：100%

## 五、实战案例

在财报问答场景中，原始PDF抽取后表格顺序错乱，导致“同比/环比”被颠倒。修复方案：
1. 对表格页启用专用抽取器。
2. 表头-数值绑定校验（列名一致性检查）。
3. 低置信度表格进入人工复核队列。

结果：关键字段错误率从 12% 降到 1.8%，后续检索问答准确率明显提升。

## 六、结论

语料工程的本质是“可复现的数据生产系统”。当抽取、清洗、标注、版本都可追踪时，模型优化才有稳定收益。
