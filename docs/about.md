# 关于这个博客

主题是：把想法交给AI，从超级个体走向超级团队。

先记下一个人怎么把规划、检索和工具交给模型，再记下这些能力怎么交到一支队伍里：通道、技能、记忆和边界。

仓库在 [GitHub](https://github.com/Tasarinan/Tasarinan.github.io)。
